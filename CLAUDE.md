# Claude Code project instructions
Read README.md and every docs/*.md in numerical order before coding. Treat approved requirements as source of truth; proposed defaults are not founder-approved commercial/legal decisions. Start by inspecting existing repository and writing a phased implementation plan; do not overwrite existing work. Implement vertical slices with tests and migrations. Never fake payment, availability, authorization or fulfillment. Use mock adapters locally; no production secrets. Ask only for blocking decisions, document assumptions in ADRs. Enforce tenant isolation and transactional inventory/booking locks. Run lint, typecheck, tests and update OpenAPI each phase. Do not claim completion until acceptance tests pass. See docs/10-build-plan.md for sequence.

## Mandatory constraint (founder, 28 November 2026)
No paid software subscriptions beyond Vercel, ChatGPT and Claude. Use free tiers that allow commercial use, open source, the existing Vercel plan and free GitHub; payment providers may charge per transaction only with founder approval. Never register, buy, activate or upgrade a paid service, start a trial as if it were free, or enable pay-as-you-go or overages. No AWS, no Twilio or SMS. Hosting is Vercel; database and storage are Supabase Free; email is Resend Free; push is Firebase Cloud Messaging (Spark). Keep adapter interfaces so paid services can be added later with approval. Never weaken security, payment integrity, data protection or financial accuracy to save cost. See docs/adr/0024-cost-constraints-and-vercel-first-architecture.md, docs/FOUNDER_DECISIONS.md and docs/INFRASTRUCTURE_COSTS.md. Never ask the founder to paste keys into chat; point to docs/FOUNDER_SETUP_GUIDE.md.
