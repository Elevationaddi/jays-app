# Security and QA review (phase 11)

Date: 28 November 2026. Reviewer: the development team (Claude), from the code and the automated tests. **This is not an external penetration test or a legal compliance certification.** No real-device testing has been performed.

## 1. Controls in `docs/09-security-testing.md`

| Control                                                   | How it is met                                                                                                                                                                                                                        | Evidence                                                            |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| Password hashing                                          | Argon2id (19 MiB, t=2, p=1)                                                                                                                                                                                                          | `auth/crypto.ts`, `crypto.test.ts`, `auth.int.test.ts`              |
| Verified email or phone, code expiry and throttling       | One-time codes stored as HMACs, expiry, attempt limits, resend cooldown, per-IP and per-identifier rate limits                                                                                                                       | ADR-0009, `auth.int.test.ts`                                        |
| Phone flows without SMS                                   | Refused with `SMS_UNAVAILABLE` when no SMS provider exists (no Twilio, ADR-0024)                                                                                                                                                     | `notify.int.test.ts`                                                |
| Admin MFA                                                 | TOTP required for every admin; secrets encrypted at rest (AES-256-GCM)                                                                                                                                                               | ADR-0010, `admin.int.test.ts`, browser smoke test                   |
| Short access tokens, refresh rotation and reuse detection | 15-minute JWTs (HS256 pinned, audience and issuer checked); rotation under row lock; reuse revokes the session; session checked on every request                                                                                     | ADR-0009, `auth.int.test.ts`                                        |
| Mobile token storage                                      | Expo SecureStore (Keychain / Keystore)                                                                                                                                                                                               | `apps/customer`                                                     |
| Web sessions                                              | HttpOnly, SameSite=Lax, Secure in production; tokens stay on the portal server (BFF); server actions checked by Next.js for same origin                                                                                              | ADR-0011, `session.ts`                                              |
| Open redirects                                            | `returnTo` accepted only as a same-site path                                                                                                                                                                                         | `safeReturnTo` in both portals                                      |

| Strict CORS                                               | Explicit origin list; https only in production                                                                                                                                                                                       | `bootstrap.ts`, `env.ts`                                            |
| Input validation and output encoding                      | Zod on every request body and query; React escapes output; emails escape every value                                                                                                                                                 | `common/zod.ts`, `email-templates.ts`                               |
| Parameterised queries                                     | Kysely everywhere. The only raw SQL fragments are fixed constants (`JOB_SQL`), never user input                                                                                                                                      | review of `sql.raw` uses                                            |

| Uploads                                                   | Signed, single-object, short-lived URLs; real type from magic bytes; size and image-shape limits; ClamAV scan that fails closed; failed files deleted; private documents only through short-lived links with access checks and audit | ADR-0012, ADR-0032, `storage.int.test.ts`, `onboarding.int.test.ts` |

| Account deletion                                          | In-app request, grace period, anonymisation with statutory retention                                                                                                                                                                 | ADR-0019                                                            |

| Security headers                                          | Helmet on the API; CSP `frame-ancestors 'none'`, `nosniff`, referrer and permissions policies, HSTS on portals and the web build                                                                                                     | `next.config.ts`, CI check, browser smoke test                      |
| Background jobs on Vercel                                 | Cron routes need a secret (constant-time compare), 404 when unset, excluded from OpenAPI                                                                                                                                             | `cron.int.test.ts`                                                  |

## 2. Findings

| #   | Finding                                                                                                                            | Severity                                    | Status                                                                                                  |
| --- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 1   | Business documents (up to 10 MB) went through server actions, which would fail on Vercel (4.5 MB)                                  | Medium (availability)                       | **Fixed** in phase 10: direct browser upload                                                            |
| 2   | Portals sent no anti-framing or HSTS headers (clickjacking risk on admin actions)                                                  | Medium                                      | **Fixed** in phase 10                                                                                   |
| 3   | No malware scanner host                                                                                                            | High for production                         | **Open, founder decision** (ADR-0032). Production cannot start without one, so it cannot ship unscanned |
| 4   | Photo metadata (such as location) is not stripped from uploaded images                                                             | Low to medium (privacy)                     | **Open:** needs the `sharp` image library, which needs the founder's approval                           |
| 5   | Dependency audit: 1 moderate advisory (`minimatch`, through Expo's build-time fingerprint tool), none high                         | Low (build tooling, not in the shipped app) | Accepted until Expo updates it; CI fails on high                                                        |
| 6   | Data stored outside the UAE (Supabase Mumbai)                                                                                      | Legal                                       | **Open, lawyer**                                                                                        |
| 7   | Raw webhook body handling on Vercel not yet observed                                                                               | Medium until checked                        | **Open:** first staging check in `DEPLOYMENT.md`                                                        |
| 8   | Guest cart tokens and webhook signature headers were written to request logs (a cart token lets its holder change that guest cart) | Low                                         | **Fixed** in phase 11: redacted, with a test                                                            |
| 9   | Signed image URLs (short-lived) appear in request logs as paths                                                                    | Low                                         | Accepted: image tokens expire and grant read access to one public-facing image only                     |
| 10  | No external penetration test or dynamic scan                                                                                       | n/a                                         | **Recommended before production:** an OWASP ZAP baseline scan (open source, no cost) against staging    |

No open high-severity code finding is known from this review. Items 3 and 6 block production.
